# Five Nights at Freddy's — HTML Collection

A web-based collection of **Five Nights at Freddy's games**, playable directly in your browser.

The project brings multiple FNAF games together in one place using HTML, CSS, and JavaScript.

## 🤝 Contributing

Contributions, bug reports, and improvements are welcome.

If you find a bug or have an idea for improving the project:

1. Check the existing [Issues](https://github.com/irv77/hd_fnaf/issues).
2. Open a new Issue if the problem has not already been reported.
3. Fork the repository.
4. Create a branch for your changes.
5. Make and test your changes.
6. Submit a Pull Request.

Please keep changes focused and explain what was changed and why.

## 🐛 Bug Reports

When reporting a bug, please include:

- Which game is affected
- What you expected to happen
- What actually happened
- Browser and version
- Operating system
- Steps to reproduce the problem
- Screenshots or videos when useful
